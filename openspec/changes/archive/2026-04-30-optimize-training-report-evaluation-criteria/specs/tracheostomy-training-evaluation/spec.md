## ADDED Requirements

### Requirement: 会话数据采集
系统 MUST 从现有训练运行时事件与器械尖端位姿中采集评价数据，并将步骤事件、触发事件、重试事件、异常流程事件和位姿采样关联到同一训练会话。

#### Scenario: 记录步骤生命周期事件
- **WHEN** 训练步骤开始、结束、重试或被强制结束
- **THEN** 系统 MUST 记录事件类型、时间戳、步骤编号、会话编号和当前步骤状态。

#### Scenario: 记录尖端位姿流
- **WHEN** Marker、Scalpel 或 Tracheal 尖端在对应步骤激活期间发生运动
- **THEN** 系统 MUST 按配置采样率记录尖端位置、旋转、采样时间戳和关联步骤编号。

#### Scenario: 生成结构化会话记录
- **WHEN** 训练会话结束
- **THEN** 系统 MUST 生成包含原始事件、位姿采样和会话元数据的结构化记录，供评分、报告和本地导出复用。

### Requirement: 双路径方向有效性
系统 MUST 将横切和竖切都支持为可配置的合法训练路径，并通过评分配置控制当前训练场景允许的方向集合。

#### Scenario: 横切路径判定通过
- **WHEN** 当前配置允许横切且切开方向在水平参考轴阈值内
- **THEN** 系统 MUST 将该方向判定为有效路径。

#### Scenario: 竖切路径判定通过
- **WHEN** 当前配置允许竖切且切开方向在垂直参考轴阈值内
- **THEN** 系统 MUST 将该方向判定为有效路径。

#### Scenario: 双路径模式取最小方向误差
- **WHEN** 当前配置允许横切和竖切且系统计算方向误差
- **THEN** 系统 MUST 使用水平参考轴误差和垂直参考轴误差中的最小值作为步骤角度误差。

### Requirement: 分步骤量化指标
系统 MUST 基于采集数据在目标区域局部坐标系中计算分步骤量化指标，以降低模型位姿变化对评价结果的影响。

#### Scenario: 计算定位步骤指标
- **WHEN** Step1 定位数据可用
- **THEN** 系统 MUST 输出定位角度误差、定位中点偏移和标记长度。

#### Scenario: 计算切开步骤指标
- **WHEN** Step2 或 Step3 切开数据可用
- **THEN** 系统 MUST 输出方向误差、切开长度、切口中心偏移和路径效率。

#### Scenario: 计算插管步骤指标
- **WHEN** Step4 插管数据可用
- **THEN** 系统 MUST 基于碰撞体插入状态输出插管成功状态。

#### Scenario: 插管稳定停留和角度不作为本次判定依据
- **WHEN** 系统计算 Step4 插管指标
- **THEN** 系统 MUST NOT 要求稳定停留时长或插管角度误差作为本 change 的插管判定依据。

### Requirement: 评分与门槛逻辑
系统 MUST 可重复、确定性地产生主评分、分步评分和门槛结论，并保证同一输入与同一配置产生一致结果。

#### Scenario: 同一输入产生一致评分
- **WHEN** 系统使用相同输入指标和相同评分配置重复执行评分
- **THEN** 系统 MUST 输出一致的最终得分、分步得分和门槛结论。

#### Scenario: 门槛失败覆盖通过结论
- **WHEN** 任一门槛条件失败，包括跳步、逆序、关键步骤未完成或危险事件超阈值
- **THEN** 系统 MUST 将整体状态设置为未通过，且不得仅因数值得分较高而判定通过。

#### Scenario: 观察指标不参与主评分
- **WHEN** 系统计算最终主评分
- **THEN** 系统 MUST 将完成时间、分步耗时、重试次数和总重试次数的主评分权重视为 0。

### Requirement: 手势交互公平性控制
系统 MUST 针对 OpenXR 手势输入噪声提供平滑、防抖和稳定窗口机制，降低瞬时抖动或误触对评价结果的影响。

#### Scenario: 短时误触不计为有效证据
- **WHEN** 一次接触或触发持续时间低于防抖阈值
- **THEN** 系统 MUST 忽略该接触或触发，不得将其计为有效操作证据。

#### Scenario: 连续满足后确认有效性
- **WHEN** 切开或插管有效性条件连续满足设定帧数
- **THEN** 系统 MUST 确认该有效性成立，并记录确认时间戳。

### Requirement: 教学报告与本地数据导出
系统 MUST 同时提供面向学员反馈的教学报告和面向教学复盘/调试追溯的本地结构化导出。

#### Scenario: 输出教学报告
- **WHEN** 训练会话完成评分
- **THEN** 系统 MUST 展示最终得分、分步得分、门槛状态、观察指标和可执行改进建议。

#### Scenario: 输出本地数据
- **WHEN** 用户触发本地数据导出
- **THEN** 系统 MUST 生成 CSV 和 JSON 数据，包含原始指标、标准化指标、门槛状态、字段说明和版本字段。

#### Scenario: 导出版本追溯字段
- **WHEN** 系统生成任一本地导出记录
- **THEN** 系统 MUST 包含算法版本、评分配置版本和场景版本字段。

### Requirement: 系统可用性验收
系统 MUST 提供基于用户实操结果的验收证据，证明评价体系具备训练用途，而不依赖新增被试招募或科研分析。

#### Scenario: 实操结果字段核对
- **WHEN** 用户完成实操测试并提供训练报告或本地导出结果
- **THEN** 系统 MUST 支持核对采集、评分、报告和导出字段是否与本次实现目标一致。

#### Scenario: 核心分支验收
- **WHEN** 用户提供横切、竖切、双路径、明显偏移、危险事件或关键步骤未完成等实操结果
- **THEN** 系统 MUST 支持核对评分与门槛结论是否符合预期。

#### Scenario: 重复计算一致性
- **WHEN** 同一会话数据在相同评分配置下重复计算
- **THEN** 系统 MUST 输出一致的最终得分、分步得分、门槛状态和导出内容。

#### Scenario: 重复训练趋势展示
- **WHEN** 同一操作者存在多次重复训练会话
- **THEN** 系统 MUST 可视化展示关键误差指标和主评分的变化趋势，用于教学复盘和训练反馈闭环。
